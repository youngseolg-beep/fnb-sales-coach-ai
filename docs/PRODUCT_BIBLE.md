# Sales Coach AI Product Bible

Sales Coach AI는 일일 매장 운영 데이터를 **입력 → 측정 → 분석 → 실행**으로 바꾼다.

## Roles and Security

- **Store User:** 인증된 하나의 `store_id` 범위에서 매출·메뉴·보고서를 운영한다.
- **Master:** 여러 매장을 대시보드와 상세 화면에서 관리·모니터링한다.

Supabase Auth 세션은 지속·자동 갱신되며, 역할과 store_id 프로필을 확인한다. 불완전한 세션/프로필은 실패 닫힘으로 처리한다. RLS는 매장 데이터와 Coach 보고서 접근을 제한한다. 공개 테스트 RPC 제거, 오래된 SECURITY DEFINER 정리, trigger `search_path` 고정, 평문 가입 비밀번호 제거·유출 비밀번호 보호를 반영했다.

## Store Owner

- **Home:** 오늘 상태, 입력 현황, 월 매출/목표, 바로가기
- **Sales:** 로컬 날짜의 POS·배달 매출, 주문, 방문객, 메뉴 수량, OCR, 조정, 저장/삭제
- **Coach:** 완료 기간 KPI·추이·메뉴 비교, Menu Engineering, AI 메뉴 전략, Boost Plan, 범위별 보고서 복원
- **Menu:** 메뉴 마스터, 판매가, 단위원가, 가격 이력
- **More:** 매장 정보, 빠른 도움말, AI 안내, Guided Tour, 로그아웃

인증된 매장은 메뉴 마스터가 비어 있거나 로드에 실패하면 가짜 기본 메뉴 대신 설정 미완료 오류를 본다.

## Sales and OCR Rules

날짜는 브라우저 로컬 `YYYY-MM-DD` 기준이다. 입력 매출은 POS+배달 매출이고 메뉴 매출은 `판매가 × 수량` 합계다. 주문·방문객은 별도 지표이며 매출 차이는 화면에서 확인한다.

OCR은 이미지에서 메뉴 후보를 추출하고 사용자가 검토 후 적용한다. 미해결/검토 필요 메뉴, 인식 메뉴 없음, 미래/잘못된 날짜, 통화 불일치, 소계와 메뉴 합계 불일치는 적용을 막는다. **매장명 불일치·미인식은 경고만 표시**한다. OCR 실패에도 수동 입력은 유지된다.

## Coach, Menu Engineering, Boost Plan

Menu Engineering은 기간 판매·가격·원가 데이터를 결정론적으로 사용한다.

- STAR: 판매·수익성 강함
- CASH_COW: 판매 강함, 수익성 상대적으로 낮음
- PUZZLE: 수익성 강함, 판매 상대적으로 낮음
- DOG: 둘 다 약함

AI 메뉴 전략은 분류를 설명할 뿐 대체하지 않는다. 분석은 선택 기간을 쓰며 최근 최대 60일을 사용한다.

Boost Plan은 결정론적 후보를 먼저 만들고 AI가 후보 기반 행동을 작성한다. 유효 후보 수에 따라 1~3개 행동이 나오며 개수를 채우기 위해 행동을 발명하지 않는다. 승인 근거 없는 확정 할인·쿠폰·무료 제공·세트 가격은 허용하지 않으며 가격/세트 실행은 원가·공헌이익 확인이 선행된다.

Gemini API는 구조화 JSON을 검증하고 제한된 재시도를 한다. 실패해도 기본 KPI·결정론적 결과는 보존하며 완료/실패 보고서는 매장·기능·기간 범위로 저장될 수 있다.

## Master and Context

Master 비교는 Today=어제, This Week=이전 주 동일 경과 길이, This Month=이전 달 동일 경과 기간, Last 30 Days=직전 30일, Custom=직전 동일 길이 기간을 사용한다.

통화는 country에서 파생한다. DEMO/KH는 USD, JP는 JPY, NL은 EUR 등 지원 매핑을 따른다. DEMO는 일반적인 국가/브랜드 가이드를 위한 명시적 컨텍스트다.

## Failure Principles and Glossary

AI 실패에는 기본 데이터, OCR 실패에는 수동 입력, 네트워크 오류에는 현재 입력을 보존한다. 권한 오류는 실패 닫힘으로 처리한다.

| 용어 | 의미 |
|---|---|
| 메뉴 매출 | 판매가×수량으로 계산한 금액 |
| 매출 차이 | 입력 매출과 메뉴 매출의 차이 |
| AI 메뉴 전략 | 메뉴 분류 기반 AI 우선순위 |
| AI 부스트 플랜 | 안전 조건 내 실행 제안 |
| OCR | 영수증 추출·메뉴 매칭 |
